# Estruturas de dados em Java · Senac

Exercício de implementação de uma lista simplesmente encadeada em Java. O programa de exemplo usa objetos `Carro` para demonstrar a estrutura.

## Como explorar

- [Lista e operações](src/lista/Lista.java)
- [Nó da lista](src/lista/No.java)
- [Programa de exemplo](src/principal/UsaLista.java)

O projeto inclui configuração do NetBeans e um [arquivo de build do Ant](build.xml). Abra a pasta do repositório no NetBeans e execute a classe `principal.UsaLista`.
